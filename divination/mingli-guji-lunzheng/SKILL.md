# 命理古籍论证法（Mingli Guji Lunzheng）

用户核心要求（2026-08-07 确立，适用于所有八字/命理论断）：

> **严格以《滴天髓》《子平真诠》《穷通宝鉴》《三命通会》《渊海子平》为主要依据，凡古籍无据者不妄断，禁止套话与迎合，输出验证性最高的结论。**

## 执行铁律

1. **凡古籍无据者不妄断**——每个核心论断必须能指到具体古籍条文（书名+原文）。指不出的不下结论，或明确标注"推演，无古籍明文"。
2. **引原文、标出处**——引用古籍前先核实原文（见下"原文抓取"），不用记忆中的模糊转述。
3. **禁止套话与迎合**——不用"晚成大器/黄金十年/名利双收/先苦后甜"等无出处的现代激励语；不因用户处境（失业、赔钱、焦虑）而软化结论；好坏都直说。
4. **调候为急**——八字论断次序：先按月令定格局与用神（《穷通宝鉴》逐月明文，如"五月戊土，先看壬水，次取甲木，丙火酌用，用癸力微"），再论日主强弱与病处（《滴天髓》），大运顺逆（《渊海子平》），流年流月推应期。
5. **验证性分级**（用户要"验证性最高结论"时只给前两级）：
   - 古籍明文（如宝鉴"先看壬水"）→ 直接引用
   - 古籍推演（如滴天髓"坐寅怕申"推申月应期）→ 注明推理链
   - 经验类比（无明文、仅流派习惯）→ 不主动给，明确说"此条无古籍明文"
6. **应期落到流年流月**——大运（阳男阴女顺逆法）+ 流年流月干支作用（如"丙申月申金冲日支寅，应滴天髓坐寅怕申"），逐层推，不停在泛论。
7. **时辰/流派分歧如实并陈**——真太阳时 vs 钟表时、拆补 vs 置闰等分歧两版并列，各自标注依据，不强行二选一。

## 补充典籍（2026-09-21 扩充）

五部为纲之外，另备**九本典籍核心规则摘要**：`references/extra-classics-nine-books.md`（吸收自 GitHub jinchenma94/bazi-skill ⭐3154，MIT）——含**《千里命稿》（现代实证派批断）、《协纪辨方书》（择日神煞体系）、《果老星宗》（星命/七政四余）、《神峰通考》（病药说：以"病"取用神）**，以及前五部的规则速查（格局/调候/旺衰/气势流通）。

**用法与优先级**：五部有明文 → 以五部为准；五部未覆盖处（择日神煞、病药取用、星命互参）→ 可引补充典籍，但**必须标注"（补充典籍，非五部明文，验证性降一级）"**。补充典籍不改变"五部为纲"的原则，也不用于替代原文核实。

## 原文抓取方法（维基文库，已验证）

古籍全文在 zh.wikisource.org，HTML 去标签后可检索：

```powershell
$r = Invoke-WebRequest -Uri 'https://zh.wikisource.org/wiki/穷通宝鉴' -TimeoutSec 30 -UseBasicParsing
$text = [System.Net.WebUtility]::HtmlDecode(($r.Content -replace '<[^>]+>',' '))
$text = $text -replace '\s+',' '
$idx = $text.IndexOf('四月戊土')   # 正文标题；目录在前，搜正文标题避开目录
$text.Substring($idx, 3000)
```

- URL 规则：`https://zh.wikisource.org/wiki/<书名>`；《滴天髓》URL 编码为 `%E6%BB%B4%E5%A4%A9%E9%AB%93`
- 页面正文在目录之后：搜正文标题（如"四月戊土"=三夏戊土正文起点）而非目录条目（"三夏戊土"）
- 备选：ctext.org（中国哲学书电子化计划，可搜书名）；国内网络 raw.githubusercontent 常超时，用 wikisource/ctext 更稳
- 关键原文速查：`references/guji-quotes.md`（已核实的五部古籍关键条文摘录）

## 时辰修正铁律（大经度差）

出生地经度偏离东经120°超过约 ±7.5°（时差≥30分钟）时，**必须做真太阳时修正**，并向用户确认出生记录基准：
- 记录为**北京时间** → 按记录时辰排盘（如新疆 07-09 点 = 辰时）
- 记录为**当地时间** → 真太阳时修正后可能跨时辰（如新疆某地 88.5°E 比北京慢125分钟，辰时实际是卯时）
- 两版并列呈现，标注依据，不强行二选一（案例见 `references/guji-quotes.md`）

## 已核实的五月戊土论断（案例示范）

命造 乙丑 壬午 戊寅 丙辰（男，示例命主甲 辰时，北京时间）：
- 《穷通宝鉴》五月戊土："先看壬水，次取甲木，丙火酌用"——壬透甲藏，格降一等（非"君臣庆会"两透）；"若支成火局……一杯水难济薪火"，午月+寅午合火+丙透=火局已成，唯一救应"若得壬水出干"（月干壬水正是命门）
- 《滴天髓》戊土："火燥喜润""坐寅怕申，盖冲则根动"——日支寅为暗线，逢申年/申月/申运根基必动
- 大运：戊寅运（32-42）比肩合火最燥→丁丑（42-52）印劫火土→丙子（52-62）水火既济，一生最得力
- 8月丙申月：申冲寅（滴天髓应期）+ 申中庚金生壬水（宝鉴"金妻水子"，财源得生）+ 丙火盖头夺食（渊海子平枭神夺食）→ 根基有动、财路有芽但被夺，宜守宜润
