# 命理古籍考据与论证（Mingli Kaozheng）

面向内行用户的命理论证方法。用户可能明确要求"严格以古籍为依据，凡古籍无据者不妄断，禁止套话与迎合，输出验证性最高的结论"——**这是硬性标准，不是风格偏好**。

## 核心铁律

1. **五部古籍为纲**：《滴天髓》《子平真诠》《穷通宝鉴》《三命通会》《渊海子平》。论断只基于这五部（及其公认注本）
2. **论断分层标注**：每个结论标明依据层级——「古籍原文」＞「古籍逻辑推导」＞「民间口诀/经验谈」＞「现代命理推断」。**严禁把民间说法冒充古籍原文**
3. **引用原文必须核实**：引文来自维基文库原文，不凭记忆编造；拿不准就标"转述大意"
4. **实证反馈优先于理论**：用户提供的实际经历（"35-40 很顺""找桃花后财运好"）是第一修正信号。用「运岁相济」解释表面矛盾，**不硬圆**
5. **禁止套话**：不用"晚成大器""黄金十年""名利双收"等无据鼓励语；验证性结论不好听也直说（"合伙是命盘明示的破财口"）
6. **禁止迎合**：用户问"是不是没问题/是不是就活了"，答案是"不是"就要直说，附古籍逻辑

## 古籍原文获取（维基文库，国内可直连）

```powershell
$r = Invoke-WebRequest -Uri 'https://zh.wikisource.org/wiki/<书名>' -TimeoutSec 30 -UseBasicParsing
$text = [System.Net.WebUtility]::HtmlDecode(($r.Content -replace '<[^>]+>',' ')) -replace '\s+',' '
# 页面开头是目录！正文定位用章节名二次搜索（跳过目录）
$idx = $text.IndexOf('<章节名>', 5000)   # 如 '四月戊土'（三夏戊土正文从四月起）
```

- 《穷通宝鉴》：`https://zh.wikisource.org/wiki/穷通宝鉴` —— 正文按"论X木/三春/三夏/三秋/三冬"分节；"三夏戊土"只在目录出现一次，正文定位用 `IndexOf('四月戊土')`
- 《滴天髓》：`https://zh.wikisource.org/wiki/滴天髓` —— 正文含原文+注释，`IndexOf('戊土固重')` 直达
- 提取后 `IndexOf` 定位 + `Substring` 截取，验证关键句在结果中

### 已核实关键原文（戊土系）

- **《穷通宝鉴》五月戊土**："五月戊土，仲夏火炎，**先看壬水，次取甲木，丙火酌用，用癸力微**。壬甲两透，名君臣庆会……若支成火局，即透癸水，不能大济，是一杯水难济薪火也。……用壬者，金妻水子。"
- **《滴天髓》论戊土**："戊土固重，既中且正，静翕动辟，万物司命。**水旺物生，火燥喜润**，若在坤艮，怕冲宜静。" 注："其气属阳，喜润下恶燥，**坐寅怕申，坐申怕寅，盖冲则根动**。"

## 口诀考据方法（"这句话出自哪"类问题）

1. 先搜古籍原文（维基文库/ctext.org），再搜网络
2. 查不到 → 如实说"古籍无据，系民间口诀/顺口溜"，**不硬找出处**
3. 但拆内核：口诀往往有古籍推导链，把推导链讲清楚（见实例）

### 考据实例：「桃花不采变成财」

- **结论**：非五部古籍原文，系近代民间顺口溜（网络检索无经典出处）
- **内核有据**：男命以财为妻星（《渊海子平》"财者妻财也"）→ 桃花=异性缘=财星活跃态 → 同一能量用在情上是桃花、用在人脉上是财。推导链合法，句子本身是民间演绎
- 方法论示范：**句子出处与逻辑内核分开讲**，不因句子伪而否定逻辑，也不因逻辑真而冒充经书

## 真太阳时修正（西部省份必查）

出生地经度 <110°E（陕西以西）必须做真太阳时修正，否则时辰错位、整盘皆偏：

- 偏移 = (经度 − 120°) × 4 分钟 + 均时差（EoT，Spencer 公式）
- **实测案例**：新疆某地 88.5°E 慢约 125 分钟——北京时间 7-9 点实际是卯时（非辰时）；取 8:00 → 真太阳时 05:55 → 卯时
- **处理原则**：用户确认记录为北京时间 → 钟表时直排为基准（A 版），真太阳时版作对照（B 版），两版并列呈现
- **分歧影响巨大**（实测）：同一生辰卯时 vs 辰时——时柱乙卯→丙辰（十神正官→偏印）、紫微命宫太阳巨门→廉贞七杀、五行局土五→火六。**必须标注，不许含糊**
- 工具：`mcp__mingyu__calendar_true_solar_time` 或 Python（lunar_python 的 Solar.fromYmdHms）

## 运岁相济（大运 × 流年叠加判吉凶）

- 大运是十年基调，流年是逐年应期；**大运燥但流年补用神 → 照样顺**
- **实测案例**：戊寅燥运（32-42）+ 2020-2023 庚辛壬癸金水连珠 → 用户 35-40 很顺。结论："水来即顺、水走即难"，实证宝鉴"先看壬水"
- 逐年判断 = 大运五行 + 流年干支五行 + 与命局用神/忌神关系，三者叠加
- 流年干支用 lunar_python 验证（`Solar.fromYmdHms(y,3,1).getLunar().getEightChar().getYear()`），不手推

## 输出：古籍论证版 + 说人话版

用户可能要两版，明确标注、并存：

- **古籍论证版**：引用原文（带书名），对照命局列表，分层标注依据，验证性结论直说
- **说人话版**：白话转述，"你这命盘说白了就三句话"，对照用户实际处境（表格），给落地建议
- 两版都带边界声明：命理是传统文化符号体系，非科学预测；不构成投资/医疗/婚姻决策依据

## 商业模式命理论证（应用框架）

用十神/五行结构分析实际生意模式：

| 模式要素 | 命理对应 |
|---|---|
| 吃信息差/做流通节点 | 壬水偏财（流动之财）——用神本职 |
| 养团队干活 | 比劫争财（《子平真诠》论比劫：比劫重重财星被分）——利润摊薄 |
| 资质/门面/非常规手段 | 偏印（主资质、门面）——为忌但擅长 |
| 产能外包 | 借他人食伤（金）生我财——把短板外包 |
| 下游依赖单一 | 食伤弱则依赖单一=危险，多养备胎 |

**实测案例**（2026-08-07）：保险收单（信息差=壬水 ✅）→ 数据标注（属水行业 ✅）→ 公司养十几人（比劫争财 ⚠️）→ 改门面团队+下游转包（自己当壬水节点、产能外包 ✅，但枭神夺食防交付翻车、门面人=暗比劫、旱季薄利）。结论："对的模式，错的时机"——2026-2027 旱季守，2028 戊申（申金生水）转机，2031 辛亥（亥水得禄）爆发。

## 桃花类问题处理框架（命理+实操）

用户问"桃花采不采/怎么处理"时：

1. **先定性**（三问）：见不见光（金星12宫最怕暗）、耗不耗你、长辈认不认（红鸾在父母宫=正缘通道是长辈介绍，自己撞的多半非正缘）
2. **没发生关系**：拖延测试+带进生活圈+守住底线（没定性前不发生）
3. **已发生关系**：重新定性重新定价——正缘就推"见光+长辈+长期"（忌星化吉靠正名分）；消耗型就明确降温、别拖、补偿不纠缠
4. **"桃花旺财"修正**：若用户反馈"找桃花后财运好"——桃花可能=用神（异性缘=财星活跃态），但因果要分清：不是"桃花→财"，是"用神活跃→既招桃花又发财"（并列非因果）。激活用神最划算的方式是业务而非桃花

## 时代周期 × 个人大运（2026-08-07 实测框架）

用户问"我的大运和赤马红羊、九紫离火有什么关系"时，用三层叠加框架：

| 层级 | 周期 | 本质 |
|---|---|---|
| 个人大运 | 十年一运 | 个人五行气候 |
| 时代 | 九紫离火运 2024-2043 | 离卦属火——大环境五行 |
| 年份 | 赤马红羊（丙午/丁未） | 火年（源出南宋柴望《丙午丁未议》） |

- **命局喜忌 × 时代五行**：命喜水忌火 + 生于火时代 → "逆风开局"，但时代之火也指向风口行业（离火=AI/数据/电子——数据标注正属此，方向没错）
- **关键洞察**：个人大运在时代中段转水（丙子运 2036-2046 子水正财）→ 火时代之尾接个人水运 → "时代之火将熄、个人之水正旺"是最值得压注的窗口
- **行业姿势**："火行业、水人" → 以水济火（做流通/撮合/信息差节点），不跟火拼火（重资产/重技术/重规模）
- 赤马红羊不是神秘劫数，是五行应期：火年克命局用神水，诸事不顺的周期解释

## 占星流年推运与八字互证（2026-08-07 实测）

用户指出"八字紫微奇门都进来了，西方占星没进来"——**排了星盘却没用上**是工作流缺口。修正：

- 本命盘解读必须进交叉验证（上升/太阳/月亮落座、宫位、相位、格局 Grand Trine/T-Square 等）
- **流年推运必须与八字流年互证**：用 mingyu-core 的 `astrolabe-scope` 模块（详见 western-astrology skill 计算层 2.2 条）
- 实测 API 要点（2026-08-07）：
  - `buildAstrolabeScopeContext(natal, 'yearly', '2026')` —— **dateStr 只传年份 YYYY**，传完整日期报错"流年必须提供 YYYY 格式"
  - `generateAstrolabe(...)` 返回值用 `raw?.result ?? raw` 兜底再取 `.planets`
  - `ctx.promptText` 含：本命宫主星、主要行运相位（如"天王星☌上升 精准合相"）、行运落宫、太阳返照、次限推进、太阳弧
- 互证案例（2026-2028）：2027 天王星合上升（精准 0.10°）↔ 八字丁未年丑未冲"根基重组"；2028 土星拱天顶 ↔ 八字戊申"转机元年"——两系统同向即高置信
- **编排层提醒**：mingli-synthesis 伞形编排时，占星子 skill 排了盘就必须进第 4 步交叉验证，不允许"只排盘不解读"

## 边界与提醒

- 五部古籍内部也有流派分歧（如晚子时归属、藏干取法）——标注所用流派
