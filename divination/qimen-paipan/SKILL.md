# 奇门遁甲起局（QiMen Paipan）

## 用途

按时家奇门（转盘法）排出奇门局，用于：择时（何时行动有利）、问事（当前局势的进退判断）。本 skill 负责**起局**，解读由调用方完成。

## 计算层优先级（2026-08-07 更新）

1. **首选 `mcp__mingyu__divine_qimen` / `qimen_prompt`**（mingyu MCP 已接入 Hermes）：转盘/飞盘可切换、拆补/置闰可切换，输出天地人神四盘、值符值使、格局标签（入墓/击刑/伏吟反吟/门迫）、节令背景。参数：`question` + 可选 `customDate`（ISO 8601 带时区）
2. **回退**：按下方算法手工起局（标注拆补/置闰、八神顺逆流派）
3. 时间说不准不卡死，用当下时间起局并告知用户

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| ask_time | 是 | 问事/择时时间（缺省用当前时间） |
| direction | 否 | 择时用：想行动的方向（八门方位） |
| question | 是 | 问什么事（决定看哪个宫/门） |

## 起局步骤（核心算法，时家转盘奇门）

### 1. 定局数（拆补法或置闰法，标注流派）
- 以节气和日干支定阴阳遁 + 局数
- 阳遁：冬至后到夏至前（阳气上升，一至九局顺排）；阴遁：夏至后到冬至前（九至一局逆排）
- 局数 = 由节气所在"三元"（上元/中元/下元）查"节气三元局数表"（如：冬至上元阳一局、中元阳七局、下元阳四局…）
- 常用"拆补法"：以节气当日干支甲子/甲午/己卯/己酉为上元（符头）定三元

### 2. 排地盘三奇六仪
- 六仪：戊己庚辛壬癸；三奇：乙丙丁
- 阳遁：戊落局数宫，顺布六仪、逆布三奇（戊己庚辛壬癸丁丙乙顺序顺宫排）
- 阴遁：戊落局数宫，逆布六仪、顺布三奇
- 口诀："阳遁顺仪奇逆布，阴遁逆仪奇顺布"

### 3. 定旬首、值符、值使
- 时干支查旬（甲子旬/甲戌旬/甲申旬/甲午旬/甲辰旬/甲寅旬），旬首为六仪之一（戊己庚辛壬癸）
- **值符** = 旬首六仪对应的九星（地盘旬首所在宫的原九星）
- **值使** = 旬首对应的八门

### 4. 排天盘九星
- 值符星随时干落宫（"值符随时干"），其余八星按原宫位关系顺转

### 5. 排八门
- 值使门随时宫落宫（"值使随时支"）：从旬首地支数到用时地支，值使门每宫走一宫（阳遁顺、阴遁逆）
- 八门顺序：休、生、伤、杜、景、死、惊、开（对应八宫）

### 6. 排八神
- 值符、腾蛇、太阴、六合、白虎(勾陈)、玄武(朱雀)、九地、九天
- 值符神随值符星，其余顺排（阳遁顺转，阴遁逆转；流派差异需标注）

### 7. 九宫基础信息
- 九宫：坎一(北,水)、坤二(西南,土)、震三(东,木)、巽四(东南,木)、中五(寄坤二)、乾六(西北,金)、兑七(西,金)、艮八(东北,土)、离九(南,火)
- 八门吉凶参考：开休生为三吉门，伤杜景死惊为凶平（结合旺衰看）

## 工具与校验

- Python 库：`lunar_python` 支持奇门遁甲排盘（`Qimen` 类，拆补法/置闰法可选），优先使用
- 手工起局自检：阴阳遁方向、局数查表、值符值使定位、八神顺逆
- 无法可靠起局 → confidence: low 并注明

## 诚实边界

- 拆补法 vs 置闰法、八神顺逆、超神接气等流派分歧必须标注
- 奇门"用神取法"（问事看哪个宫）流派众多，输出需注明用神选取逻辑
