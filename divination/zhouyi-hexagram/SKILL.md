# 周易起卦（ZhouYi Hexagram）

## 用途

起卦（得卦象）并装卦：本卦、变卦、动爻、六亲、世应、纳甲。本 skill 负责**起卦与装卦**，卦辞解读由调用方完成。

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| ask_time | 推荐 | 梅花易数时间起卦用（缺省当前时间） |
| question | 是 | 问什么事 |
| method | 否 | 时间起卦（默认）/ 金钱卦（需用户摇卦记录） |

## 起卦方法

### 方法 A：梅花易数·时间起卦（默认，无需道具）
1. 取年月日时数：年支序数（子1丑2…亥12）、月数、日数、时支序数
2. **上卦** = (年 + 月 + 日) ÷ 8 取余（余 0 为 8 坤）；**下卦** = (年 + 月 + 日 + 时) ÷ 8 取余
3. **动爻** = (年 + 月 + 日 + 时) ÷ 6 取余（余 0 为 6 爻动）
4. 先天八卦数：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8

### 方法 B：金钱卦（传统六爻）
三枚铜钱摇六次，从下往上记：三正=老阳(○,动)、三反=老阴(×,动)、两正一反=少阳(、)、两反一正=少阴(,,)。得本卦；动爻位阴阳互换得变卦。**需要用户实际摇卦**，AI 不可替用户摇。

## 装卦步骤

1. **定本卦/变卦**：由上下卦查八宫卦序得卦名（乾为天、天风姤…）
2. **定动爻**：梅花易数由余数得；金钱卦由老阳老阴得
3. **装六亲**：以本卦宫（八宫属性）五行生克定：生我者父母、我生者子孙、克我者官鬼、我克者妻财、同我者兄弟
4. **定世应**：八宫卦世应口诀（如八纯卦世在 6 爻，一世卦世在 1 爻…）——查八宫卦序表最稳
5. **纳甲**（可选）：乾纳甲壬、坤纳乙癸、震纳庚、巽纳辛、坎纳戊、离纳己、艮纳丙、兑纳丁；地支按卦宫顺排

## 工具与校验

- Python 库 `iching`、`lunar_python`（含六爻/梅花易数支持）可辅助，但起卦数理简单，手算可靠
- 自检：上下卦数对应先天卦序、动爻 1-6 范围、卦名正确（可用 64 卦序表核对）、六亲生克方向
- 金钱卦必须由用户真实摇卦；用户未摇卦时只能用时间起卦

## 诚实边界

- 起卦是确定性数理；**卦辞解读**存在多解（义理派/象数派），输出需标注解读视角
- 一事一卦原则：同一问题短期内不应反复起卦
- 不动不占、不诚不占是传统原则，AI 应尊重用户自主性，不诱导迷信
