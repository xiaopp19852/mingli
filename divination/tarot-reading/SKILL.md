# 塔罗占卜（Tarot Reading）

## 用途

用塔罗牌阵解读当下处境与趋势。本 skill 负责**抽牌与牌意组织**，最终解读与整合由调用方完成。

## 计算层优先级（2026-08-07 更新）

1. **首选 `mcp__mingyu__divine_tarot` / `tarot_prompt`**（mingyu MCP 已接入 Hermes）：78 张塔罗真随机抽牌，支持单牌/时间流/爱情/事业/选择牌阵，含正逆位与关键词，返回结构化牌阵 + 可直接解读的提示词
2. **回退**：本 skill 下方的抽牌规则（用户抽牌或 AI 随机，注明方式）
3. 用户坚持自己抽牌时尊重用户选择（心念集中传统），按用户报牌名组织解读

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| question | 是 | 问什么事（开放式问题最佳，避免是非题） |
| spread | 否 | 三张牌阵（默认）/ 凯尔特十字 / 单张 |
| cards | 否 | 用户自己抽牌时提供牌名；否则由 AI 随机抽 |

## 牌组（韦特塔罗 78 张）

- **大阿卡纳 22 张**：0 愚者、I 魔术师、II 女祭司、III 皇后、IV 皇帝、V 教皇、VI 恋人、VII 战车、VIII 力量、IX 隐士、X 命运之轮、XI 正义、XII 倒吊人、XIII 死神、XIV 节制、XV 恶魔、XVI 高塔、XVII 星星、XVIII 月亮、XIX 太阳、XX 审判、XXI 世界
- **小阿卡纳 56 张**：四组（权杖=火/行动、圣杯=水/情感、宝剑=风/思维、星币=土/物质）× 14 张（Ace-10 + 侍从/骑士/王后/国王）

## 常用牌阵

### 三张牌阵（默认）
- 位置 1：过去/背景
- 位置 2：现在/核心
- 位置 3：未来/趋势

### 凯尔特十字（10 张，深度分析）
1 现在、2 阻碍、3 潜意识、4 过去、5 目标、6 近未来、7 自我、8 环境、9 希望恐惧、10 结果

## 抽牌规则

- **用户抽牌**：让用户报牌名或从 78 张中选（尊重"心念集中"的传统）
- **AI 随机抽**：用随机数发生器抽（注明"随机抽取，非真实洗牌"）
- 每张牌标注正位/逆位（逆位 = 牌意减弱、受阻或内在化）

## 解读框架（每张牌输出）

1. 牌面核心意象（1-2 句）
2. 正/逆位含义
3. 在该牌阵位置上的具体含义
4. 与问题的关联

```yaml
    - {position: 现在, card: 宝剑九, reversed: true, core: "焦虑、担忧（逆位：开始走出）", in_context: "当下有焦虑但已在缓解"}
    - {position: 未来, card: 星币十, reversed: false, core: "财富积累、家族成就", in_context: "长期看有稳定收获，宜着眼长期"}

  - "整体牌面火元素(权杖)→风(宝剑)→土(星币)：从行动到思维再到落地"

```

## 工具与校验

- 牌意基于韦特塔罗经典释义，可参考《塔罗葵花宝典》等标准教材
- AI 随机抽牌时用 `random` 或 `secrets` 模块，保证不可预测性
- 逆位判定：随机时 50% 概率；用户抽牌以用户声明为准

## 诚实边界

- 塔罗是投射工具（心理学视角：帮助人整理潜意识），非预测工具
- 同一问题短期不重复抽牌
- 不替用户做重大决定，不制造恐惧（如"高塔"也解读为"破除旧结构的契机"）
- 用户抽牌时 AI 不可"替抽"或"代洗"
