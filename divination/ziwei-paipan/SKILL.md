# 紫微斗数排盘（ZiWei Paipan）

## 用途

排出紫微斗数命盘：十二宫位、主星辅星分布、四化、大限。本 skill 负责**排盘**，解读由调用方完成。

## 计算层优先级（2026-08-07 更新）

1. **首选 `mcp__mingyu__ziwei_prompt` / `ziwei_calculate`**（mingyu MCP 已接入 Hermes，底层用 iztro 引擎）：十二宫/主星/辅星/生年四化/大限/流年/三方四正全支持，披露安星口径（闰月/晚子时）。参数：`dateType, year, month, day, gender, timeIndex`（紫微必需时辰）
2. **回退**：按下方算法手工排盘（标注所用流派：三合/飞星/四化）
3. 出生时辰未知时**不要自行补时辰**——紫微排盘强依赖时辰，请用户补足后再排

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| birth_solar | 是 | 公历日期时间（紫微斗数以农历月日排盘，需先换算农历） |
| gender | 是 | 大限顺逆依据（男命阳男阴男…实为生年干阴阳 + 性别决定顺逆） |
| birth_place | 推荐 | 真太阳时修正，同八字 |

## 排盘步骤（核心算法）

### 0. 农历换算 + 时辰
公历 → 农历（年、月、日、时）。时辰同八字（子时 23:00 起，晚子时流派分歧：部分流派按次日日数排盘）。

### 1. 安命宫、身宫
- 命宫：**寅宫起正月，顺数至生月，再从生月宫起子时，逆数至生时** → 落宫即命宫
- 身宫：同法但**顺数至生时**（命逆身顺）

### 2. 定十二宫
从命宫起，逆时针（或按流派顺排）依次：命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、仆役(交友)、官禄、田宅、福德、父母。

### 3. 定五行局（水二局/木三局/金四局/土五局/火六局）
由命宫干支的纳音五行定局（如：命宫干支纳音属水→水二局）。口诀："甲子乙丑海中金…" 纳音五行表查命宫干支。

### 4. 安紫微星
以农历生日与五行局数，按"紫微星诀"求紫微所在宫位：
- 水二局：生日 1/3/5/7/9… 对应紫微落寅/子/…（有固定表格）
- 通用口诀："水火二局寅申起，木三局丑未起，金四局辰戌起，土五局巳亥起，火六局卯酉起"；再按生日奇偶顺逆推
- **查表最稳**：五行局 × 生日 → 紫微落宫（标准速查表）

### 5. 安十四主星
- **紫微星系**（逆排）：紫微 → 天机(紫-1) → 太阳(机+1) → 武曲(日-1) → 天同(武+1) → 廉贞(同+5)
- **天府星系**（顺排）：天府(紫-5... 实际为紫微对宫) → 太阴 → 贪狼 → 巨门 → 天相 → 天梁 → 七杀 → 破军（口诀："天府太阴顺贪狼，巨门天相与天梁，七杀空三是破军"）

### 6. 安辅星
左辅右弼（按月份+时支）、文昌文曲（时干起）、天魁天钺（年干）、禄存（年干）、擎羊陀罗（禄存前后）、火星铃星（时支+年支）、天马（年支）等，各有起法口诀。

### 7. 安四化（禄权科忌）
按**生年天干**定：甲廉破武阳（甲廉贞化禄、破军化权、武曲化科、太阳化忌），乙机梁紫阴，丙同机昌廉，丁阴同机巨，戊贪阴弼机，己武贪梁曲，庚阳武阴同，辛巨阳曲昌，壬梁紫左武，癸破巨阴贪。**（现代排盘也常用"飞星四化"，需标注流派）**

### 8. 大限
- 阳男阴女顺行，阴男阳女逆行（从命宫起）
- 大限岁数：五行局数起（水二局 2-11 岁，木三局 3-12 岁…每宫十年）

## 工具与校验

- Python 库：`lunar_python` 支持紫微斗数排盘（`lunar_python` 的 `Lunar` 类有紫微相关 API），优先使用避免手工误差
- 手工排盘必须自检：命宫顺逆方向、五行局查表、紫微落宫、四化年干口诀
- 无法可靠排盘 → confidence: low 并注明

## 诚实边界

- 排盘算法流派众多（三合派/飞星派/四化派），四化和部分星曜安法有分歧，必须标注流派
- 星曜"庙旺利陷"程度表有标准版本，但解读权重是主观的
