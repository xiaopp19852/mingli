# 奇门格局（凶格）白话释义速查（2026-09-23 用户问\"这些是什么意思\"后沉淀）

**格局是什么**：奇门里\"**天盘干 + 地盘干（+落宫）**\"组合成的固定判词，像成语——一个组合对应一句古已有之的吉凶断语。用户看到一堆格名发懵时，按本表逐条给\"**构成 + 传统主象 + 说人话**\"三列。

## 使用纪律（必守）

1. **凶格不是死刑**：临吉门吉星 → 降级为\"虚惊\"（\"门吉星吉则虚禁无劳\"先例：狱入天牢遇休门/生门）。报告里凶格后必须带补救条件，不做恐吓式输出
2. **问事局断的是\"节奏/通不通\"，不是\"命\"**：格局密集＝\"此刻推进阻力大\"，正确译法是\"稳守到 X 窗口\"，不是\"你完了\"
3. **优先引用引擎白话**：`r.patternDetails[].summary` 自带白话释义（如\"门伏吟：八门回原位，事项推进迟滞，宜耐心等待\"）——直接引用比自己翻书准
4. **不确定就不引原文**：个别格（青龙逃走、蛇入狱刑）各派构成说法不一——只给主象并注明\"构成各本不一\"，**禁止编造古籍逐字引文**
5. **配套读**：应期看 `r.yingQi`（rhythm + triggerConditions，禁自编天数）；宫位看 `renPan{door}`/`shenPan{god}`；择方看 SKILL.md「择方」原则（不照搬 `r.directions`）
